# Divider

A horizontal line separating groups of elements inside a section.

```lua
section:Toggle({ Text = "enable", Flag = "enable" })

section:Divider()

section:Slider({ Text = "speed", Min = 1, Max = 10 })
```

No options. It spans the width of the section and follows the theme.

For a divider between tabs in side mode, see [Tabs](../interface/tabs.md#dividers). For one inside a panel header, the panel draws its own.
